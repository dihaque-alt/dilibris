### 42. Кнопки — hover без прозорості
Глобальні стилі `index.css` більше не перебивають `.dl-primary` / `.dl-ghost` на hover.

### 43. Розширити каталог книг
Більше книг, які можна знайти й додати — Open Library, Google Books, ISBN, кращий пошук українською тощо. **Не** про розмір UI на полиці.

**Файли:** `openLibrary.ts`, `googleBooks.ts`, `AddBookModal.tsx`

### 44. Fallback обкладинок
Якщо Open Library не знайшов cover — чиста типографічна обкладинка без шарів texture поверх битого img.

### 45. Нагадування
Toggle «Нагадування читати» прибрано з налаштувань (поле в prefs лишається для сумісності).

## Великі ідеї (v4 продовження)

### 46. Нотатки — прив’язка до книги
Зараз нотатки — masonry по всьому екрану. Ціль: візуально згрупувати нотатки однієї книги (stack / accordion / mini-shelf), щоб контекст читання був очевидний.

**Питання для дизайну:**
- Групувати за `book_id` з обкладинкою-якорем?
- Розгортати книгу → список нотаток?
- Зв’язок з fly-out книги?

**Файли:** `NotesPage.tsx`, `screens-ui.css`, можливо новий `NotesByBook.tsx`

### 47. Місячний дайджест (Storygraph-style)
За бажанням користувача — згенерований підсумок місяця: книги, сторінки, час, топ-автори, графік. Можна як сторінка `/digest/2026-06` або PDF/card для шерінгу.

**Залежності:** `stats.ts`, `dashboardSync.ts`, opt-in у Settings.

### 48. Щотижневий дайджест на пошту
Toggle «Тижневий дайджест» уже є в Settings (`weeklyDigest` у `app_prefs`), але листи ще не відправляються.

**Потрібно:**
- Edge function / cron (Supabase + Resend або подібне)
- Шаблон листа українською
- Unsubscribe link
- Respect `weeklyDigest: false`

**Файли:** нова `supabase/functions/weekly-digest`, `userSettings.ts`, email template
