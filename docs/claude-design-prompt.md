# DiLibris — промпт для Claude Design

Скопіюй цей блок у Claude (Design / Artifacts) після того, як функціональний кістяк працює.

---

## Контекст продукту

**DiLibris** — україномовний веб-застосунок (mobile-first) для читачів 25–30 років. Це **особиста віртуальна бібліотека прочитаного**: не Goodreads-клон, а **затишна кімната з полицями**, де книги — головні герої.

**Емоція:** затишок, радість, теплота — «твоя бібліотека», не SaaS-дашборд.

**Технічний кістяк уже є:** полиці, картка книги, відгуки, нотатки, дашборд, buddy reads. Потрібен **візуальний шар** поверх існуючої логіки.

---

## Головний екран — віртуальна бібліотека

### Концепція
- Кімната з **дерев’яними полицями** (теплий inter’єр, м’яке освітлення).
- На полицях — **обкладинки книг** (front-facing, не корінці).
- Юзер **сам створює полиці** (без ліміту); різні полиці можуть відповідати статусам: хочу прочитати, читаю, прочитано тощо.
- **Tap на книгу** → обкладинка «вилітає» вперед (hero, playful but not frantic).
- **Tap на обкладинку** → картка зі статистикою читання.

### Placeholder обкладинки
- Якщо обкладинки немає: **кіт з ножиком** (вже є як SVG placeholder — можна зробити ілюстративніше).

## Візуальний стиль

| Параметр | Напрямок |
|----------|----------|
| **Стиль кімнати** | Ілюстративний / semi-realistic 2.5D або warm flat з глибиною — **не** холодний corporate UI |
| **Кольори** | Теплі дерев’яні тони, крем, м’який lime/olive акcent, приглушений золотистий |
| **Світло** | Вечірня лампа, м’які тіні, відчуття «вдома» |
| **Типографіка** | Заголовки — serif (книжкова); UI — clean sans українською |
| **Dark mode** | v2 (не обов’язково в першому дизайні) |
| **Accessibility** | Reduced motion варіант для fly-out анімації |

### Референси (настрій, не копіювати)
- Storygraph — дашборд і статистика (раціональний шар)
- Goodreads — challenge / прочитано N книг
- Animal Crossing — затишок кімнати
- Literal / Fable — bookish social, але DiLibris **менше** social feed, більше «моя бібліотека»

---

## Екрани для дизайну

1. **Бібліотека (головна)** — кімната + полиці + fly-out обкладинка  
2. **Картка книги** — статус, прогрес, сесії, рейтинг, відгук, нотатки  
3. **Дашборд** — reading challenge, графіки (книги/місяць, автори, формат)  
4. **Buddy read** — група, прогрес учасників, чат, спільні нотатки  
5. **Auth** — magic link, мінімалістично, в тому ж теплому стилі  
6. **Empty states** — порожня полиця, перша книга, offline  

---

## Компоненти UI

- **Полиці:** draggable feel (навіть якщо v1 без drag — вигляд «меблів», не список).
- **Картки книг:** обкладинка + тонкий status pill (українською).
- **Модалки:** додати книгу (пошук + вручну), фільтри — bottom sheet на mobile.
- **Рейтинг:** зірки 1–5 з кроком 0.5.
- **Відгуки:** завжди публічні; нотатки — private/public badge.
- **Offline banner:** ненав’язливий, не ламати затишок.

## Copy / мова

- **Лише українська** в UI.
- Тон: дружній, «ти», без канцеляриту.
- Приклади: «Читаю зараз», «Не дочитала», «Рахувати в challenge», «Buddy reads».

---

## Deliverables (що прошу від Claude Design)

1. **Design system** — кольори, типографіка, spacing, радіуси, тіні.  
2. **Mockups** — mobile (375px) + desktop (1280px) для головної бібліотеки та картки книги.  
3. **Комponent specs** — полиця, book tile, fly-out animation storyboard, stat chips, challenge bar.  
4. **CSS tokens** — готові змінні для інтеграції в існуючий Vite + React проєкт (`--bg`, `--accent`, …).  

---

## Обмеження (не малювати)

- Не потрібен 3D-рендер на весь екран (важко в вебі) — достатньо **переконливої 2D/2.5D ілюстрації** або CSS-depth.
- Не social feed / follow — цього немає в v1.
- Не paywall / premium — безкоштовно назавжди.

## Поточний код (для розробника)

Стек: Vite + React + TypeScript + Supabase. Стилі в `src/index.css`, компоненти в `src/components/`, сторінки в `src/pages/`. Замінити functional UI на новий візуал, **не** міняти data model.
