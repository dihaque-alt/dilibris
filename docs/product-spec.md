# DiLibris — product spec (v1)

Окремий проєкт від D.O.Brief. Пет-проєкт, безкоштовно назавжди.

---

## Одним реченням

**DiLibris** — особиста віртуальна бібліотека прочитаного з затишком полиць, повним трекінгом читання, публічними відгуками, нотатками (private/public) і buddy reads.

---

## Аудиторія і тон

| | |
|---|---|
| **Хто** | Читачі 25–30, жінки та чоловіки |
| **Емоція** | Затишок, радість, теплота |
| **Мова UI** | Лише українська |

---

## Платформа v1

| | |
|---|---|
| **Клієнт** | Web (mobile-first responsive) |
| **Backend** | Supabase (Postgres + Auth + RLS) |
| **Auth** | Email magic link + Google OAuth (Supabase) |
| **Offline** | Так — локальний кеш + sync при reconnect |
| **Sync** | Один акаунт, кілька пристроїв |

**Стек клієнта (рекомендація):** Vite + React + TypeScript + `@supabase/supabase-js` + IndexedDB (напр. Dexie) для offline queue.

---

## Фічі v1 (усі обов’язкові)

### Віртуальна бібліотека

- Кімната з **полицями**, які юзер **створює сам** (без ліміту книг).
- Різні полиці для різних **статусів** читання.
- Tap → обкладинка «вилітає» → tap → картка книги зі статистикою.
- Placeholder обкладинки: **кіт з ножиком**.

### Статуси книги

`want_to_read` · `reading` · `finished` · `dnf` · `re_reading`

### Трекінг (ручний прогрес)

- Дати початку / завершення, сторінки, хвилини, сесії читання
- Формат: paper · ebook
- Рейтинг **1–5 з кроком 0.5**
- Перечитування: окремий запис + «рахувати в challenge?»

### Відгуки і нотатки

- Відгук: текст + рейтинг, **завжди публічний**
- Нотатки: цитати, думки, спойлери, сторінка/розділ; private/public

### Buddy reads, дашборд, challenge — див. data-model

### Імпорт

- **v1:** пошук + ручне додавання
- **Пізніше:** завантаження CSV з Goodreads (масовий перенос бібліотеки)
